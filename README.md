# Лабораторная работа 1. Консольный набор утилит

## Зависимости

- Python 3.12+
- [uv](https://docs.astral.sh/uv) - установка окружения и зависимостей
- `typer`>="0.27.2"
- `pytest`>="8.4.2"

## Запуск проекта

1. Установить зависимости:

```shell
uv sync
```

2. Активировать виртуальное окружение:

```shell
source .venv/bin/activate
```

3. Запустить утилиту:

```shell
python -m toolkit --help
```
```shell
python -m toolkit calc "0.1 + 0.2"
```
```shell
python -m tookit convert 1000 --from m --to km
```

Тесты:

```shell
pytest
```

4. Установить хуки pre-commit (если планируете коммитить):

```shell
pre-commit install
```

## Команды

`calc` принимает выражение в кавычках. Поддерживаются `+`, `-`, `*`, `/`, десятичные числа, унарные знаки и пробелы. `*` и `/` выполняются раньше `+` и `-`. Скобки не поддрерживаются.

```shell
python -m toolkit calc "2 + 3 * 4"
```
```shell
python -m toolkit calc "-2 * -3"
```

`convert` переводит значение между единицами одной группы:

| Группа | Единицы |
| --- | --- |
| Длина | `mm`, `cm`, `m`, `km` |
| Масса | `g`, `kg` |
| Температура | `c`, `f`, `k` |

Регистр единиц не важен. Параметры `--from` и  `--to` обязательны.

```shell
python -m toolkit convert 2.5 --from kg --to g
```
```shell
python -m toolkit convert 0 --from c --to f
```

## Решения, принатые при разработке

- Точка входа - модуль `toolkit`. Команду `python -m toolkit` можно запускать в корне проекта.
- Токенизация, валидация и вычесление разделены.
- Унарный `+` и `-` приклеиваются к числу на этапе токенизации, если перед ними начало строки или другой оператор. Поэтому работают записи вроде `-5+2` и `5--2`.
- Калькулятор считает на `Decimal`, а не на `float`: точность 28 знаков(дефолтное значение), округление `ROUND_HALF_UP`. Так десятичные дроби не накапливают десятичную погрешность.
- Температура ниже абсолютного нуля запрещена. Сам абсолютный ноль (`0 K`,`-273.15 C`) допустим. Для срвнения результатов с плавающей точкой в тестах используется `pytest.approx`.
- Типы проверяются строго: Pyright в режиме `strict`, mypy смотрит в `src` через `mypy_path`.
